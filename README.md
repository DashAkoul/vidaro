## What is Vidaro?

Vidaro is a free desktop YouTube downloader and download manager. It lets you download a single YouTube video, an entire playlist, or videos from a channel, while giving you control over quality, format, subtitles and download management.

There is no subscription or payment required to use the application.

## Why use Vidaro?

- **Free** — no subscription and no payment required to use Vidaro.
- **Single videos, playlists and channels**.
- **Download manager** — pause, resume, cancel and retry.
- **Quality and format choices** — choose available video quality or extract audio.
- **Subtitles** — download subtitles when available.
- **Organized downloads** — keep playlist and channel downloads grouped.
- **Clipboard detection** — copy a supported YouTube link and Vidaro can offer a quick download action without a manual paste.
- **Scheduling** — schedule downloads globally or per item.
- **Proxy support** — HTTP, HTTPS and SOCKS5.
- **Light / Dark / System themes**.
- **English / Persian interface** with RTL support.
- **Windows, macOS and Linux** support.

## How it works

1. Copy or enter a YouTube link.
2. Vidaro identifies the download target.
3. Review the available videos and choose what to download.
4. Select quality, format, subtitles and download location.
5. Add the items to the queue.
6. Manage the downloads from the download manager.

## What's new in v0.3?

Vidaro v0.3 added and improved several download-manager capabilities:

- YouTube video, playlist and channel downloads.
- Windows, macOS and Linux release builds.
- Queue management with pause, resume, cancel and retry.
- Global and per-item scheduling.
- Queue and settings import/export.
- HTTP, HTTPS and SOCKS5 proxy support.
- Clipboard watcher for supported YouTube links.
- Light, Dark and System themes.
- RTL improvements.
- Bug fixes and stability improvements.

### Clipboard quick-download

When a supported YouTube link is copied, Vidaro can detect it from the clipboard and display a lightweight notification/pop-up. The user can move directly into the download workflow without manually pasting the URL.

## What's coming in v1.0?

Vidaro v1.0 is planned to add a browser extension that works alongside the desktop application.

While the user is browsing YouTube, the extension is designed to recognize whether the current page represents:

- a single video;
- a playlist; or
- videos associated with a channel.

It can then present a minimal download interface with options such as video quality, format and subtitles.
