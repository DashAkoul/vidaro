# Vidaro — SEO / GitHub setup checklist

## 1. GitHub repository description

Use a clear description such as:

> Free YouTube downloader for Windows, macOS & Linux — download videos, playlists and channel videos with queue management, subtitles, scheduling and proxy support.

## 2. Repository topics

Suggested GitHub topics:

```text
youtube-downloader
youtube-video-downloader
youtube-playlist-downloader
youtube-channel-downloader
youtube-downloader-windows
youtube-downloader-macos
youtube-downloader-linux
video-downloader
download-manager
tauri
rust
react
typescript
yt-dlp
ffmpeg
```

Use only topics that accurately describe the current project.

## 3. Important search phrases

Use these naturally in the README and website:

- YouTube downloader
- free YouTube downloader
- YouTube video downloader
- YouTube playlist downloader
- YouTube channel downloader
- download YouTube videos
- YouTube download manager
- Windows YouTube downloader
- macOS YouTube downloader
- Linux YouTube downloader

Do not repeat keywords unnaturally.

## 5. Stronger Google visibility

A GitHub repository can be indexed by Google, but for stronger search control create an official project website or GitHub Pages site.

The site should have:

- a unique descriptive page title;
- a concise description;
- useful text explaining the product;
- screenshots;
- download links;
- a link to the GitHub repository;
- a stable canonical URL when appropriate.

Then verify the site in Google Search Console and monitor queries and clicks.

## 6. Do not promise a ranking

No README change can guarantee a top Google position. Search visibility depends on indexing, relevance, competition, links, content quality and many other signals.

The goal should be to make Vidaro clearly understandable and discoverable for real searches such as:

```text
youtube downloader
youtube playlist downloader
youtube channel downloader
free youtube downloader
youtube download manager
youtube downloader windows
youtube downloader mac
youtube downloader linux
```

## 7. Version updates

For v1.0:

- replace v0.3 filenames;
- add the browser extension screenshot;
- add supported browsers;
- document extension installation;
- document extension-to-desktop communication;
- update the feature list;
- update release links only where filenames are version-specific.
